# Founders' agreement checklist

Not legal advice. Use this to have the conversation, then have a lawyer turn it into a real agreement (especially if it runs through Sabins Sound LLC).

- [ ] **Ownership split** — percentages, and whether it vests over time (e.g. 4 years, 1-year cliff).
- [ ] **Entity** — new LLC, existing company, or none yet? Who holds the IP until then?
- [ ] **IP assignment** — all Patch Pilot code, designs and docs belong to the entity, not either person.
- [ ] **RigSync** — is its code contributed to Patch Pilot? Who owns it?
- [ ] **Decisions** — what needs both founders (pricing, selling, taking investment, hiring) vs either one.
- [ ] **Time commitment** — expected hours per week; what happens if that changes.
- [ ] **Money** — who pays for Apple Developer, code signing, hosting; how it's reimbursed.
- [ ] **Revenue** — how profit is split before and after costs.
- [ ] **Selling the company** — can one founder block a sale? Right of first refusal on shares?
- [ ] **Walking away** — what a departing founder keeps (vested only?), and buyback terms.
- [ ] **Accounts** — GitHub org, domain, Apple/Microsoft developer accounts, payment processor all owned by the entity, both founders as admins.
